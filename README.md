# Tower of Hanoi - Japanese Edition

A Tower of Hanoi game with Japanese themes. SWI-Prolog runs the server
and all game logic, and the browser handles animation and sound.

## How to run
1. Install SWI-Prolog 9 or newer from https://www.swi-prolog.org and tick "Add swipl to the PATH".
2. Download towerofhanoi.pl from this page.
3. Open a terminal in the folder with the file and run:
   swipl towerofhanoi.pl
4. Your browser opens the game. If not, go to http://localhost:8080/

## Features
- 4 modes: Easy, Hard, Difficult, Nightmare, plus a hidden Random mode
- Live demo preview on each mode panel
- Single player (undo, restart, pause) or multiplayer (2 to 4 players)
- Ranking with ties and a best-10 leaderboard saved to leaderboard.json
